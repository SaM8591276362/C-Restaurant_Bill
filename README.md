# C-Restaurant_Bill
A simple restaurant billing system developed using C programming language to calculate food bills based on selected items and their quantities.

## About the Project
The Restaurant Billing System is a console-based application developed using the C programming language. It helps calculate restaurant bills based on the food items selected by customers and their quantities.

## Features
- Display food menu.
- Select food items.
- Enter item quantities.
- Calculate total bill.
- Display final billing details.

## Technologies Used
- C Programming Language
- VS Code

## How to Run
1. Download or clone this repository.
2. Open the `.c` file in a C compiler.
3. Compile the program.
4. Run the executable file.
5. Follow the on-screen instructions.

- Understanding of conditional statements.
